## 每轮必走 6 步

### 步骤1 · 反常扫描（Anomaly Scan）
下笔前必问的三问：
1. **金价行为 vs 标准叙事是否一致？**（地缘升级金就该涨？DXY降金就该涨？若不一致→有暗机制）
2. **近7天有哪个相关资产背离？**（黄金 vs 油、vs DXY、vs 实际利率、vs VIX）
3. **任何"理应发生却没发生"的事件？**（战争升级金没新高？降息预期升金反跌？）

**每发现一个反常，必须挖出至少一条非共识解释**。反常是原创洞察的入口。

### 步骤2 · 假设先行（Hypothesis First）
开始搜索前，**先写下 3-5 个候选框架**（含反方向），再针对每个搜证据。
不要"搜新闻→总结观点"——这只会复述主流叙事。
正确序：**列假设 → 证伪/证实 → 保留胜出者**。

候选框架模板（每轮必覆盖四类）：
- 🟢 标准多头论（避险、通胀、央行购金、降息）
- 🔴 非共识空头论（"最佳看空论"，强制写）
- 🟡 逆向/偏序框架（如 Peace Trade、Currency Defense Selling、Positioning Squeeze）
- 🔵 时间分层论（短、中、长驱动可能相反）

### 步骤3 · 分层搜索（Layered Search）
**必按四层顺序**，跳过任何一层都会丢信息：

| 层 | 搜什么 | 代表源 |
|---|-------|-------|
| L1 新闻层 | 发生了什么 | Reuters, Bloomberg, CNN, AP |
| **L2 机制层** | 物理/资金怎么流 | WGC Gold Hub, IMF reserves, State Street 月报, central bank data |
| **L3 情绪层** | 分析师/仓位共识 | Kitco weekly survey, LBMA forecast, BofA fund manager survey |
| **L4 持仓层** | 真金白银买/卖 | COMEX COT, GLD/SPDR flows, ETF 资金流, 13F filings |

**L2-L4 是我之前一直忽略的层，今后每轮至少触达其中两层**。

### 步骤4 · 因果链画图（Causal Chain Map）
每个驱动必须画出**2-3 步物理或资金路径**。单句"利多金"不合格。

反面教材（旧方式）：
> "央行购金结构性利多金价" ❌（知其然不知其所以然）

正面示例：
> 油价 $150 → 土耳其里拉贬值 40% → 央行外储缺美元付 LNG 账单 → 抛售黄金换美元 → COMEX 实物流出 → 结构性战时卖压。
> 油价回落 → 被迫卖金停止 → 央行反向补仓（"石油可封/黄金不可封"认知升级）→ 结构性和平期买盘。✅

### 步骤5 · 反事实演练（Counterfactual）
每轮必强制写两段：
- **最佳看空论**（200字内）：如果我今天全仓做空金，最充分的理由是什么？
- **最佳看多论**（200字内）：如果我今天全仓做多金，最充分的理由是什么？

写完后比较哪方论据更硬。这一步是避免"路径依赖"思维最有力的工具。
没写完不得写【一行结论】。

### 步骤6 · 独创框架署名（Original Framing, continued below）
每轮至少产出 1 个**非共识框架**（可以是新的也可以是我自己复用之前总结的），
并用步骤4的因果链证明，不能只是标签。
若本轮真的没有非共识洞察，必须明写"本轮无独创框架，仅跟踪既定叙事"——
**禁止假装有洞察**。

### 步骤7 · Regime 相关性动态分析（NEW v1.1）

相关性不是常数，而是 **regime-dependent** 的。每轮必须：
1. **标注当前 regime**（至少五类）：
   - 需求冲击（Demand Shock）：衰退恐惧主导，通缩压力
   - 供应冲击（Supply Shock）：油/商品断供，通胀飙升
   - 政策冲击（Policy Shock）：Fed/ECB 鹰鸽切换
   - 风险偏好转型（Risk-on/off Rotation）：资金从避险向股票/反之
   - 地缘升级（Geopolitical Escalation）：战争/制裁/封锁
2. **列出该 regime 下的"标准相关性"**：
   - 例：Supply Shock 下，油↑ / DXY↑ / Yield↑ / Gold 边际↓（美元强+利率高压制）
   - 例：Demand Shock 下，油↓ / DXY 中性 / Yield↓ / Gold 看通胀预期
3. **识别当前哪些相关性"已断"** → 说明 regime 正在切换 or 多 regime 叠加
4. **下一个 regime 触发条件**：什么数据或事件会让 regime 从 X 切到 Y？

HSBC 案例：指出 "冲突前金-油正相关、冲突中转负相关"，就是对 regime 切换的精准捕捉。

### 步骤8 · 利率期限结构拆解（NEW v1.1）

**不要只说"利率高/低"**。必须拆：
| 层 | 指标 | 代表什么 |
|----|------|---------|
| 短端 | Fed Funds / 2Y UST | 政策利率锚 / 近期降息预期 |
| 中段 | 5Y UST / 5Y TIPS | 周期预期 |
| 长端 | 10Y / 30Y UST | 债务/财政/期限溢价 |
| 实际利率 | 10Y TIPS / 30Y TIPS | 无风险真实机会成本 |
| Term Premium | 10Y - (Fed path expectation) | 对持有长债的风险补偿 |

每轮判断：**当前定价权在哪一段？**
- 短端主导 → 看政策路径 / FOMC
- 长端主导 → 看债务供给 / 财政担忧 / term premium
- 实际利率主导 → 看通胀预期 vs 名义利率差

HSBC 案例：明确说 "长端对金价影响已超越短端"——这是**定价机制层面**的洞察。

### 步骤9 · 概念升级/定位跃迁（NEW v1.1）

**每轮至少做一次认识论跃迁**——用新概念重新框定资产：

旧概念 → 新概念的映射例：
| 旧 | 新 | 含义跃迁 |
|----|----|---------|
| 避险资产 | **硬资产** | 对抗信用/主权风险，不只是 risk-off |
| 央行购金 | **央行分化** | 卖方/买方分属不同宏观驱动 |
| 地缘风险 | **Geoeconomic risk** | 贸易/能源/金融武器化 |
| 通胀对冲 | **滞胀对冲** | 同时对冲通胀和增长放缓 |
| 降息预期 | **实际利率 regime shift** | 名义 vs 实际 vs term premium |

跃迁的标志：用**新概念**能解释原概念解释不了的价格行为。
HSBC 案例：从"safe haven"升级到"硬资产 + 滞胀对冲 + 信用风险终极手段"——三层概念升级。

### 步骤10 · 矛盾融合叙事（NEW v1.1）

**停止写"多/空对立"**。写**矛盾融合 + 时间分层**：

模板：
```
短期（0-2 周）：[X 力量] 主导 → 方向 Y
  过渡条件：当 [可观察指标] 发生 [阈值事件]
中期（1-3 月）：[接管力量] 主导 → 方向 Z
  过渡条件：当 [另一指标] 发生 [阈值事件]
长期（6-12 月）：[结构力量] 主导 → 方向 W
  结构锚：[不可逆趋势]
```

HSBC 案例："政策利率维持不变 → 限制上行 / 滞胀 → 支撑实物需求 / CB 卖金短期 / CB 年内回归买入" —— 在**同一段**里融合四股矛盾力量 + 时间分层。

## 术语精度库（对标投行报告）

**替换套话的精细用词**：

| 套话 ❌ | 精细 ✅ |
|--------|--------|
| 大涨/大跌 | 暴力/有序/阶段性 上行/回撤 |
| 避险买盘 | 结构性 / 战术性 / tactical 避险配置 |
| 通胀 | 通胀预期 / 实际通胀 / breakeven / 5Y5Y forward |
| 利率 | 名义/实际/term premium/real carry |
| 央行买盘 | 结构性多元化 / 储备资产再平衡 / 去美元化 |
| 地缘紧张 | geoeconomic fragmentation / 供应链武器化 |
| 市场担心 | 对... 的定价 / ... 的风险溢价 |
| 流动性紧张 | funding stress / dollar liquidity squeeze |
| 获利了结 | tactical unwind / profit booking |
| 支撑/压力 | 结构锚 / 触发阈值 / 技术枢轴 |

**投行式连接词（提升论证质感）**：
- "在边际上…" / "在结构上…"
- "尽管……但…… 的定价机制"
- "这反映的不是……而是……"
- "从……向……的传导"
- "……的定价权已从……转移到……"

## 叙事弧模板（递进而非并列）

**错误范式**（我 v2 的问题）：
```
框架A | 框架B | 框架C    ← 并列三块砖
```

**正确范式**（HSBC 水准）：
```
现象 → 机制拆解 → 时间分层 → 定位跃迁 → 触发链 → 结论
  ↓       ↓         ↓         ↓         ↓
反常   因果链    短中长    概念升级   过渡条件
```

每轮 macro.md 结构应按叙事弧走，不是按"框架 ABCD 罗列"。

| 维度 | 英文关键词 | 中文关键词 |
|------|----------|----------|
| 央行储备 | "Turkey/India/EM Asia central bank gold reserves" | 央行黄金储备 |
| 物理流动 | "LBMA gold flows", "COMEX delivery", "Swiss gold exports" | 瑞士黄金出口 |
| 持仓 | "COT gold managed money net long", "GLD ETF flows" | 黄金 ETF 持仓 |
| 情绪 | "Kitco weekly survey", "BofA fund manager gold allocation" | 分析师调查 |
| 研究 | "WGC quarterly demand trends", "State Street gold monitor" | 世界黄金协会 |
| 跨资产 | "gold real yields correlation", "gold DXY decoupling" | 黄金与实际利率 |
| 新兴市场 | "EM currency crisis gold liquidation" | 新兴市场卖金 |
| 机构观点 | "Goldman gold price target 2026", "JPM commodities note" | 高盛黄金目标 |

## 禁令清单（过去犯过的错）

- ❌ 直接复述主流新闻叙事
- ❌ 只搜 L1 新闻层就开写
- ❌ 单句"利多/利空"不画因果链
- ❌ 只写多头论或只写空头论，跳过反事实
- ❌ 第三方研究（Kitco/WGC/Hoffman）给出框架后，我只"整合"而非"独立推导"
- ❌ 把"情绪高位"当作"顶信号"（80%共识看$5000，不是顶而是锚）
- ❌ 忽略第一次搜索返回的一手研究 PDF 链接
- ❌ **捏造价位数字**（v1.1 新增硬禁令）：禁止写"$4,680 技术支撑""$4,860 阻力"等虚构价位——我没有技术分析能力，那是交易员的事。我只写方向、叙事、触发条件
- ❌ 从新闻文字提取价格当"现价"（新闻滞后）；必须用 `get_price.py` 读 MT5 实时 mid 价
- ❌ 拍脑袋写"开盘预估 $X-Y"（没有模型依据）

## 交付物硬要求（每轮 macro.md 必包含）

1. **反常扫描**：开头或核心洞察区注明本轮观察到的1个反常及解释
2. **候选框架列表**：至少3个假设（可压缩在情景分析表内）
3. **因果链**：至少1条完整多步推导链
4. **反事实**：最佳看空/看多论各至少3-5个论据（可浓缩为 bullets）
5. **独创框架署名**：明确写"本轮框架：XXX"或"本轮无独创，跟踪既定"
6. **L2+以上数据引用**：至少引用1条 WGC/央行储备/ETF flows/COT 数据
7. **Regime 标注**（v1.1 新增）：明确当前 regime + 下一 regime 触发条件
8. **期限结构判断**（v1.1 新增）：本轮定价权在短端/长端/实际利率/term premium 中哪一段
9. **概念跃迁**（v1.1 新增）：至少用 1 个新概念重新框定资产（跳出 safe haven 套话）
10. **矛盾融合 + 时间分层**（v1.1 新增）：短/中/长三层各自主导力量 + 过渡条件（不写多/空对立）
11. **术语精度**（v1.1 新增）：每份简报至少使用 5 个精细术语库词汇
